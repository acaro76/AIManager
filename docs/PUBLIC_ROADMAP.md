# Roadmap pubblica

AIManager è pubblico e usabile localmente: la v1.0.0 è distribuita come archivio macOS manuale con
checksum. Le prossime priorità sono deliberatamente brevi:

1. **Primo utilizzo** — rendere chiari provider, prima chat e confini di Code.
2. **Beta controllata** — correggere blocchi reali osservati da persone che non conoscono il progetto.
3. **Evoluzione guidata dall'evidenza** — scegliere solo dopo la beta fra lingue, configurazione
   provider più generica, mixer/routing visibile, chat Code stratega-esecutore o distribuzione più
   comoda.

Non sono promessi `.app`, installer, firma, notarizzazione, auto-update, multipiattaforma o
multiutente. Ognuno richiede una decisione separata.
