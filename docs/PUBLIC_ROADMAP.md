# Roadmap pubblica

AIManager è già usabile localmente. Le prossime priorità sono deliberatamente brevi:

1. **Primo utilizzo** — rendere chiari provider, prima chat e confini di Code.
2. **Documentazione e sorgente pubblica** — pubblicare guide verificate in un repository nuovo e
   privo della cronologia privata.
3. **Beta controllata** — correggere blocchi reali osservati da persone che non conoscono il progetto.
4. **Prima release pubblica** — archivio macOS manuale, checksum e note legati a un commit pubblico.
5. **Evoluzione guidata dall'evidenza** — scegliere solo dopo la beta fra lingue, configurazione
   provider più generica, mixer/routing visibile, chat Code stratega-esecutore o distribuzione più
   comoda.

Non sono promessi `.app`, installer, firma, notarizzazione, auto-update, multipiattaforma o
multiutente. Ognuno richiede una decisione separata.
